# Папа, спасибо за всё

Интерактивная открытка из пяти сцен. Проект работает без сервера приложений и базы данных: после сборки его можно разместить как обычный статический сайт.

## Добавить свои фотографии

1. Положите файлы `01.jpg`–`08.jpg` в [`public/photos/`](public/photos/). Папка уже создана. Сейчас вместо отсутствующих фотографий сайт показывает оформленные заглушки.
2. Откройте [`src/data/memories.ts`](src/data/memories.ts). Для каждого снимка измените `caption`, `moment` и `alt`. При необходимости измените `src` на другой файл из `public/photos/`.
3. Поле `order` задаёт порядок в истории. `inFinalCollage: true` добавляет снимок в финальный коллаж (первые шесть выбранных фото).

Можно добавить больше или меньше фотографий: добавьте или удалите записи в массиве `memories`. Для быстрого открытия на телефоне желательно уменьшить изображения до ширины примерно 1600–2000 пикселей и сохранить в JPEG или WebP с умеренным сжатием. Если меняете расширение файла, укажите его и в `src`.

## Изменить поздравление

Все тексты сцен, включая полное письмо, находятся в [`src/data/content.ts`](src/data/content.ts). Письмо можно открыть и закрыть сколько угодно раз.

## Добавить музыку

Положите инструментальную мелодию в `public/audio/music.mp3`. После этого появится кнопка включения. Музыка начинает играть только после нажатия; без файла кнопка скрыта.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, напечатанный Vite в терминале. Для проверки итоговой версии:

```bash
npm run build
npm run preview
```

Готовые статические файлы находятся в `dist/`.

## Публикация

**Vercel:** импортируйте папку проекта в Vercel. Команда сборки `npm run build`, выходная папка `dist`. Вносите личные фото и правки текста **до** публикации.

**GitHub Pages:** для репозитория `https://github.com/имя/репозиторий` задайте переменную окружения `BASE_PATH=/репозиторий/` при сборке и опубликуйте содержимое `dist/`. Например, в PowerShell:

```powershell
$env:BASE_PATH='/имя-репозитория/'
npm run build
```

При публикации в корне домена переменная `BASE_PATH` не нужна.

## Доступность

Сайт поддерживает клавиатуру, закрытие письма и фотографий клавишей Escape и системную настройку уменьшения анимации. Музыка не включается автоматически.
